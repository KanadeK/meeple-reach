# MeepleReach v0.1.0

The first public release turns measured tabletop layouts into exact, inspectable component-placement plans.

## Highlights

- Audit current reach barriers from participant-provided comfortable reach measurements.
- Exhaustively search declared candidate slots with collision checks and deterministic priorities.
- Distinguish optimal, search-limited, impossible, invalid-input, and accessibility-gate outcomes.
- Export plan JSON, interaction CSV, accessible SVG, and a self-contained HTML report.
- Run the same planning core in the CLI and no-account browser demo.

## Install

Download `meeple-reach-0.1.0.tgz`, then:

```bash
npm install --global ./meeple-reach-0.1.0.tgz
meeple-reach demo --out ./demo
```

Requires Node.js 22 or 24. No runtime dependencies or network service.

## Verify from source

```bash
npm ci
npm run check
```

The final line must be `MEEPLE_REACH_CHECK=PASS`.

Exactness is limited to the candidate slots declared in the scenario. This release is a planning aid, not medical or legal certification.
